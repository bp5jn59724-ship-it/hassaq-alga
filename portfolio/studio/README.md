# AE portfolio
Static portfolio hub: ordinary 25,000 KZT (FORMA, NORTH, LINIA); medium 45,000 KZT (IMPULSE); maximum 60,000 KZT (NORI). All five linked sites are demonstration concepts.
Contact details intentionally pending user input. The local brief form does not send anything; it supports copy and download.
Render: branch portfolio-studio, publish directory portfolio/studio. Build check: node --check portfolio/studio/app.js.
Regenerate HTML: python build_studio.py. CSS and JS are maintained directly.
Demo HTML regeneration: python build_demos.py automatically applies upgrade_demos.py; upgrade.css files are maintained directly.
