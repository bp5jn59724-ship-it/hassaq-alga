# AE Portfolio

Единое портфолио с пятью опубликованными демосайтами, ориентировочным прайсом, описанием процесса и локальным генератором брифа.

Контакт владельца ещё не предоставлен. Форма явно ничего не отправляет и не собирает контакты. Результат можно скопировать или скачать в TXT.

Цены — редактируемые стартовые предложения, не исследование рынка. Менять одновременно в index.html, app.js и build_studio.py. Генератор build_studio.py создаёт HTML и favicon; CSS и JS редактируются напрямую.

Развёртывание: Render Static Site, ветка portfolio-studio, publishPath portfolio/studio. Build: node --check portfolio/studio/app.js.

Превью — реальные скриншоты пяти собственных демопроектов. Фотографии внутри них: Unsplash, сведения об источниках в ASSETS.md соответствующих проектов.
