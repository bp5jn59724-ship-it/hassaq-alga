# HASSAQ — пакет для Render

Готовый статический сайт ресторана: 50 позиций меню, поиск, корзина и подготовка заказа для WhatsApp.

## Размещение

1. Загрузите содержимое этой папки в отдельный репозиторий GitHub, GitLab или Bitbucket.
2. Подключите репозиторий к Render и создайте Static Site.
3. Name: hassaq-alga (если доступно).
4. Build Command: node --check dist/app.js && node scripts/verify.mjs
5. Publish Directory: dist

В корне также находится render.yaml для публикации через Render Blueprint.
Статическому сайту не нужны сервер, база данных, переменные окружения или платный тариф вычислений.
Ограничения трафика и сборок определяются текущим тарифом Render.

## Возможности и ограничения

Корзина хранится в браузере. Заказ открывается как подготовленный текст в WhatsApp; посетитель отправляет его сам.
Наличие, время и итоговую стоимость подтверждает ресторан. Онлайн-оплаты и интеграции с Poster POS нет.
Адрес опубликованного сайта отображается в панели Render после успешной публикации.
